# 开发检查点：260005

本文件保存截至 2026-09-13 的项目状态，使新电脑只依靠本仓库及授权的私有签名备份即可接续开发。当前包名为 `com.zte.mifavor.launcher`，内部版本 `260005`，显示版本 `26.9.260.908.2609081608`。用户已反馈“测试通过没有问题”，未逐项列出测试用例。

## 当前功能边界

本修改版保留原厂桌面基础，增加最近任务堆叠样式、样式入口、进入/退出动画、可见卡片点击、上滑删除及补位适配。应用内进入多任务时选择第二张任务卡，从桌面进入或仅一个任务时选择第一张。桌面项目与 LS_Augment 模块独立构建、签名和管理版本。

260004 已移除自定义内存显示、整页排序、空白页管理及最近任务额外覆盖层，详见 [PAGE_FEATURES.md](../PAGE_FEATURES.md)。260005 没有恢复这些功能；不要误以为模块已经接管了所有移除项。

## 已完成的工程独立与换机修复

- 工程自带 `original.apk`、Apktool、实际框架缓存和当前完整 Apktool 源码，不依赖模块目录。
- 固定回归基线改为跟踪的 `baselines/launcher-260005.apk`，不再依赖旧电脑被忽略的 `out/`。默认基线缺失或哈希不符时，在调用工具和读取签名配置前拒绝构建。
- `.gitattributes` 固定源码换行、保持打包资源字节原样。真实 Windows 干净克隆曾因辅助 Smali 的 LF/CRLF 差异被误拒绝；现只允许对应辅助主类/内部类的精确换行等价，其他字节和文件差异仍拒绝。
- 已用全新的实际 Git 克隆，在无 `.signing/`、无旧输出、不指定 `--previous` 的情况下完成未签名构建。全部 9,022 个非签名 APK 成员与验收基线一致，含所有 DEX、Manifest、资源、原生库及 assets。
- 固定基线门禁的 14 项检查、换行边界的 15 项检查通过。归档的详细设备/构建日志未随公开仓库上传；本文件和可执行源码检查共同保存继续开发所需的结论。
