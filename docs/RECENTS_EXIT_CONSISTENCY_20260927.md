# 260018：最近任务退出消散一致性

显示版本保持 `26.9.260.908.2609081608`，本轮功能修正使用内部版本 `260018`。

## 录屏与原因

用户提供的 `Screenrecorder-20260927-094150.mp4` 约 5.82 秒。约 1.52–1.76 秒的退出中，顶卡居中的卡堆向左滑出并淡化；约 4.42–4.72 秒的退出中，前卡靠右的卡堆基本留在原位淡出。两次触点均在清理按钮左侧的下方空白。录屏用于核对动画，不随公开源码保存其中的应用画面。

代码确认两种入口共用原厂返回桌面状态动画，但原厂按当前页处理卡片：

- `f2/h.d` 的 Overview → Normal 准备阶段先切截图，再调用 `setExitAnimTaskAlpha` 设置按页码的透明度例外，并 `snapToPage` 回到更早页。
- 状态管理器先完成动画准备，后启动动画并通知 `onStateTransitionStart`。旧实现此时才保存卡片，已晚于准备阶段。
- `ADJACENT_PAGE_HORIZONTAL_OFFSET` 经 `RecentsView$4`、`updatePageOffsets` 直接改写卡片位移，次轴也有独立属性写入。旧实现仅靠 `beforeDispatchDraw` 恢复；属性更新不保证父层重新绘制。桌面第 0 页与 App 第 1 页的回页行为不同，是与录屏差异一致的代码路径解释，尚未用实机调用轨迹验证。

## 修正范围

1. 在确认退出到桌面后、原厂截图及动画准备前，保存当前卡片位置、缩放、裁剪与层级；后续状态通知复用同一份起点。
2. 仅有效的堆叠退出跳过按页码隐藏卡片和回页。整体淡出仍沿用原厂内容透明度、时长及完成回调。
3. 原厂主轴页偏移与次轴阻力位移写入后，同步恢复捕获的卡片几何；保留绘制前的补偿作为后备。
4. 退出快照绑定真实状态动画的取消通知，包含尚未启动便取消的情况；旧动画回调以事务身份隔离，不能清除新入场后的退出或启动应用事务。重复的 Overview 通知也会释放准备后取消的退出，不重新播放入场。
5. 保留桌面顶卡居中、App 第二卡居中的入场规则、用户缩放、横屏尺寸及间距。新入场解除旧事务，启动应用、非堆叠样式和无可见卡堆不被提前接管。

未增加退出计时器或新的动画类。退出完成后继续由原厂管理隐藏视图的重置。
