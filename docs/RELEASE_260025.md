# 260025 更新说明

本次更新新增右侧扇形最近任务样式，并统一三种自定义样式的比例设置与选择界面。更新内容包含 260024 的扇形卡片与 260025 的独立缩放修正。

- 新增扇形卡片：最多五张小卡沿右侧浅弧排列，名称显示在左侧，支持上下浏览、惯性吸附、点击打开、长按侧栏和左滑移除；锁定任务保留。
- 堆叠、环绕、扇形分别提供 70%–120% 卡片比例，独立保存；切换样式时恢复各自设置。
- 三种样式选择卡统一布局，环绕与扇形预览采用冰蓝视觉。
- 修复扇形名称刷新、长按文字放大和小卡圆角问题。
- 修复扇形横屏打开时截图与实时画面方向不同造成的白场和双层重影。
- 优化环绕横屏大比例布局，增加与清理按钮的留白，同时保留卡片比例及轨道间距。

已完成 33 项源码回归、辅助 Java/Smali 同步、强制重编译、原厂资源与固定基线核验、原升级签名与实际版本核验、16 KB ZIP 对齐检查，以及本机定向安装测试。
