# 安装说明

红魔12 Pro+请下载 `12-270002.apk`。显示版本为 `27.0.000.000.2609231706`，内部版本为 `270002`，包名为 `com.zte.mifavor.launcher`。各系列安装包按机型选择；内部版本号较大不表示可以跨系列安装。

桌面依赖对应固件的特权权限、Quickstep、SystemUI和OEM接口。最低API31是原厂包声明，不能作为其他机型的安装依据。

## 签名与升级

修改版升级证书SHA-256为 `4e5c23c41de3d7d56f120309e9fe8dab7d53483c50ef18a176e00558abf7b8cb`，与原厂证书不同。首次替换原厂需要满足对应固件的系统应用与权限配置、默认HOME及最近任务服务绑定条件。

已经正确安装同签名修改版且固件匹配的设备，可通过在线更新下载同系列更高版本，并交由Android系统安装器确认。更新不卸载桌面、不清空数据、不自动提权。安装说明不提供自动兼容性预检或一键恢复功能。

## 数据保留

替换前保存旧安装包、桌面数据及对应固件恢复材料，并保留可用的备用HOME。源码中的 `original.apk` 是固定构建输入，恢复设备应使用与实际固件和安装方式相符的材料。

设备资料与恢复备份保存在私有本地位置，不上传源码或发行仓库。发行文件身份见 [270002说明](RELEASE_270002.md)。
