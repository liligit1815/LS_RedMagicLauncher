# 安装兼容性与恢复边界

本分支修改红魔10原厂系统桌面 `com.zte.mifavor.launcher`，依赖对应10系列固件的特权权限、Quickstep服务、SystemUI与OEM接口。移植候选最低API为31、目标35，不代表任意Android12及以上设备都可用；本次尚未完成红魔10设备验收。

## 同签名升级

已正确安装修改版桌面的设备，可以使用同包名、同签名且更高内部版本的 APK 覆盖升级。在线更新保留桌面数据，最终安装由 Android 系统安装器确认；它不会卸载桌面、清空数据、修改系统签名保护或自动提权。

修改版升级证书 SHA-256：

`4e5c23c41de3d7d56f120309e9fe8dab7d53483c50ef18a176e00558abf7b8cb`

包名、内部版本、显示版本、精确大小、APK SHA-256与证书字段必须和10系列独立清单一致，APK还必须具有 `com.lizhou.launcher.series=redmagic10`。红魔11清单与APK不能用于10系列在线更新。10清单已在本批次独立发布，见 [更新说明](ONLINE_UPDATES.md)。

当前红魔10内部版本已按用户确认从250002开始，显示版本为25.5.000.000.2505121541。此前25001低于固定原厂150000，用户已报告直接安装后重启回退原厂版本和标准样式。本轮纠正候选版本关系，并增加固定原厂Manifest的内部号门禁，具体重启行为仍待设备复测。历史260030移植测试号不参与新序列；250002仍低于260030，不是260030的普通在线覆盖升级。设备如何重新部署需结合实际安装状态确认，本工程没有执行卸载或清空数据。

## 首次替换原厂桌面

本分支10原厂底包为 `150000 / 15.5.000.000.2505121541`，原厂证书SHA-256为 `d7bb72ea42adfcadf52c3d641b2b40181d6a36932a81c93207db172811ca46b7`，与修改版证书不同。不能把同包名或更高版本当作普通原厂环境可直接覆盖的依据，也不能跨系列替换11与10桌面。

需要分别确认固件兼容、系统/特权身份、实际权限授予、默认 HOME 和最近任务服务绑定。应用能够启动不代表全部系统桌面能力可用；Root 存在也不能代替这些条件。

本次红魔10原厂APK不含内置 `.so`。构建保持此边界，不混入红魔11库。16KB ZIP对齐属于打包属性，不代表手机运行行为已经验证。

## 数据与恢复

替换系统桌面前应保留可启动的备用 HOME、旧 APK、桌面数据及对应固件恢复材料。`original.apk` 是构建对照输入，不能直接视为任意环境可安装的回滚包。

本工程目前没有自动安装前兼容性预检，也未提供完成完整恢复演练的一键回滚功能。构建和签名恢复工具只处理本机文件，不安装 APK、不修改手机；恢复源码与签名不等于恢复设备数据。

设备数据和恢复备份仅在本地私有位置保存，不上传源码、发行或签名仓库。当前版本身份见 [版本说明](RELEASE_250002.md)。
