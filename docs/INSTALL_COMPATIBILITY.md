# 安装兼容性与恢复边界

本项目修改红魔原厂系统桌面 `com.zte.mifavor.launcher`，依赖对应固件的特权权限、Quickstep 服务、SystemUI 与 OEM 接口。最低 API 声明为 `31`，不代表任意 Android 12 及以上设备都可用。

## 同签名升级

已正确安装修改版桌面的设备，可以使用同包名、同签名且更高内部版本的 APK 覆盖升级。在线更新保留桌面数据，最终安装由 Android 系统安装器确认；它不会卸载桌面、清空数据、修改系统签名保护或自动提权。

修改版升级证书 SHA-256：

`4e5c23c41de3d7d56f120309e9fe8dab7d53483c50ef18a176e00558abf7b8cb`

包名、内部版本、显示版本、精确大小、APK SHA-256 与证书字段必须和 [公开更新清单](https://raw.githubusercontent.com/liligit1815/lispacerelease/main/updates/stacked-desktop.json) 一致。

## 首次替换原厂桌面

原厂底包为 `160000 / 16.0.010.000.2604151532`，原厂证书 SHA-256 为 `d7bb72ea42adfcadf52c3d641b2b40181d6a36932a81c93207db172811ca46b7`，与修改版证书不同。不能把同包名或更高版本当作普通原厂环境可直接覆盖的依据。

需要分别确认固件兼容、系统/特权身份、实际权限授予、默认 HOME 和最近任务服务绑定。应用能够启动不代表全部系统桌面能力可用；Root 存在也不能代替这些条件。

原厂库保留在构建中。16 KB ZIP 对齐属于打包属性，不等同于所有原厂库在 16 KB 页面设备上均适用。

## 数据与恢复

替换系统桌面前应保留可启动的备用 HOME、旧 APK、桌面数据及对应固件恢复材料。`original.apk` 是构建对照输入，不能直接视为任意环境可安装的回滚包。

本工程目前没有自动安装前兼容性预检，也未提供完成完整恢复演练的一键回滚功能。构建和签名恢复工具只处理本机文件，不安装 APK、不修改手机；恢复源码与签名不等于恢复设备数据。

设备数据和恢复备份仅在本地私有位置保存，不上传源码、发行或签名仓库。当前版本身份见 [版本说明](RELEASE_260030.md)。
