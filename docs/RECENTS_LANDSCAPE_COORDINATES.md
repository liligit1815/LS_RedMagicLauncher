# 260016：横屏最近任务与侧边操作方向修正

这是 260016 的同轮问题修正，显示版本保持 `26.9.260.908.2609081608`，固定验收基线仍为 260005。

## 问题与范围

用户反馈横屏应用进入最近任务后出现方向异常。实际录屏约 2.299 秒由横向画幅变为居中的竖向画幅；将实际与参考录屏统一到横屏观察方向后，可以确认长按按钮横排在卡片上方、图标侧转，卡片也向上下方向让位，而参考按钮沿卡片左右侧竖向排列。清理按钮会压到展开卡片的下沿，手势条与卡堆的方向也不一致。

原厂允许 Activity 保持竖向布局，由 `RecentsPagedOrientationHandler` 呈现横屏最近任务。这与将整个 View 或整个 Activity 旋转不是同一条路径。此前菜单按窗口 X/Y 判断左右并布局，即使卡堆已经使用横屏方向处理器，菜单仍使用竖屏窗口坐标。

录屏编码画幅改变不等于全部最近任务组件转成竖屏。修复保留原厂 Activity 方向策略，不修改 Manifest，不全局锁定横屏。

## 本轮修改

- 以最近任务方向处理器的 0°、90°、270° 建立统一的视觉坐标。完整截图中心相对屏幕中线决定菜单左右侧，仍在长按成立、卡片重排之前采样；同次展开、收回和重开保持侧别。
- 按视觉左右安排卡片让位；横屏主轴为窗口 Y 时，偏移也沿该主轴进行，反向横屏同时反转符号。
- 菜单的可用宽高、系统安全边、整列按钮尺寸及弧形布局使用同一视觉方向。按钮中心映射回窗口坐标，并将图标旋转到正确的阅读方向；不再只改图标而保留错误的位置。
- 转发触摸时使用 RecentsView 到操作层的完整矩阵，原生子 View 负责旋转后的按钮命中，避免只补窗口原点造成点击偏移。
- 菜单显示期间隐藏原清理按钮，菜单结束、取消或切换时恢复此前可见性；此前为 GONE 的按钮不会被误恢复为可见。不移除原厂清理功能。
- 虚拟横屏最近任务显示期间，向 SystemUI 同步当前 touchRotation 的优先方向。原厂手势链路的排队通知在实际发送时重新读取当前优先方向，避免旧的“取消优先方向”回调覆盖已经显示的横屏最近任务。
- Overview 状态、方向变更及手势动画结束同步该状态；退出、转回竖向和视图脱离时释放。真实 Activity 已允许旋转、非堆叠样式和普通桌面沿用原厂通知。没有调用 `Activity.setRequestedOrientation()`。

主要实现位于 `LsStackActions.java`、`LsNativeStack.java`、`RecentsView.smali` 与 `RotationTouchHelper.smali`。未新增打包 helper 类，仍为 17 个。

## 自动化验证

`tools/test-launcher-side-actions.py` 执行生产 Java 类，新增“父 View 不旋转 + 90°/270° 方向处理器”场景，检查两侧判定、卡片让位、按钮列、图标角度、按钮中心命中、安全区域及清理按钮恢复。该场景专门补齐此前只旋转 View/父 View 的覆盖空缺。

将侧别判定单独恢复为原来的窗口 `centerX` 比较后，新增用例明确失败于横屏侧别检查；保留本轮修正时通过。该对照是旧坐标行为的回退实验，不是旧 APK 的实机复测。

`tools/test-launcher-overview-rotation.py` 解释执行生产 Smali 桥接和原厂通知回调中的实际指令，检查竖屏/双向横屏、样式隔离、真实 Activity 旋转、排队通知、退出、脱离和方向切换；该测试已接入统一构建。

接口职责也对照了 [AOSP NavigationBar](https://android.googlesource.com/platform/frameworks/base/+/47a70c8253705c662ad13164da1d066d450ecc9a/packages/SystemUI/src/com/android/systemui/navigationbar/NavigationBar.java)：优先方向通知用于调整手势条方向，不等同于改变 Activity 的请求方向。红魔固件的实际呈现仍以实机结果为准。

完整构建通过后，实际 APK 版本、辅助代码同步、原签名、资源保真、代码边界和 16 KB ZIP 对齐结果记录于 `docs/DEVELOPMENT_STATUS.md`。

## 实机验证边界

主机测试不能替代 Android 显示与输入验证。本轮没有已连接的手机，该历史记录不包含手势条和显示画幅切换的设备验证。

重点复测：横屏应用进入最近任务后等待、90°/270°、前后卡长按与快速重开、小窗/分屏操作、点空白关闭、点击回应用、返回桌面、转回竖屏，以及其他最近任务样式。观察卡片与菜单方向一致、按钮可点、清理按钮恢复、手势条保持正确方向、退出后没有方向残留。
