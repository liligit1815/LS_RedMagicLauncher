# 260022 参考录屏 11 的最近任务动画

显示版本保持 `26.9.260.908.2609081608`。参考输入为用户提供的 `11.MP4`；设备录屏及逐帧图片仅保存在忽略目录，不放入源码仓库。

## 行为

- 桌面入口：420 ms 左侧滑入，使用最终卡片尺寸、层间距离和高度，不再从下方放大展开。
- 竖屏及横屏应用入口：正在运行的应用保留手势释放时的实时矩形，后卡从视觉左侧入场，共用原厂结束动画进度；按住手势时已经露出的左卡连续交接，避免消失后重新入场；多任务入场至少 420 ms。正反横屏使用对应视觉方向。
- 返回桌面：冻结卡片内部布局，按实际可见卡片外边界计算移动距离，使用完整原厂状态时钟向视觉左侧移出，最后阶段才统一消散；非卡片控件保留原厂动画。统一合成避免相邻轮廓重复半透明。
- 点击应用：选中卡片沿真实远程 Surface 放大；其他卡片按捕获的屏幕位置分向两侧，在后半程消散。保留任务身份校验、原厂时钟、失败/取消恢复及晚到回调隔离。
- 横屏尺寸与清理间距、最终焦点、正常翻页和长按操作沿用已有行为。

## 验证结果

完整构建 34 步、0 失败，状态 `signed_verified`。覆盖强制 Apktool 回编译、Java/Smali 同步、原厂资源保真、代码范围、16 KB ZIP 对齐、原升级签名与实际 APK 版本。构建期间业务源码未变。

针对性主机检查包括 3,383,616 项桌面入场/四向坐标检查、174,445 项手势归属/入场交接/取消/重入检查，以及 107,525 项实际 Smali 属性覆盖、整组绘制、侧向退出和点卡启动几何/生命周期检查；原有边缘、圆角、缩放、点击命中、删除、长按、小窗路径等回归也全部通过。

删除几何测试曾出现被测 View 从模拟父容器移除后提前回收的偶发失败。测试在结束回调后增加 `Reference.reachabilityFence`，模拟原厂动画持有 TaskView 至回调返回的生命周期；未修改生产删除逻辑或放宽几何断言。
