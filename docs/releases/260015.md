# 260015 · 堆叠入场与长按操作优化

- 内部版本：`260015`
- 显示版本：`26.9.260.908.2609081608`
- 包名：`com.zte.mifavor.launcher`

## 本次更新

- **桌面上滑进入最近任务**：顶层卡片居中，后方卡片从其下方逐步向左展开，配合整组上移和缩放过渡；只有一个任务时保持居中。
- **保留应用内入口布局**：从 App 进入时，前卡在右、第二张卡居中，后卡向左展开。
- **长按卡片连续展开**：长按后所选卡片居中展开，相邻卡片退开并淡出；调整动画节奏与截图裁剪，减少邻卡截图突然露出和过渡前快后停的现象。
- **操作按钮按需显示**：所有卡片默认隐藏操作按钮，长按仅显示所选卡片的原厂右上角按钮，操作完成或取消后全部隐藏；隐藏按钮区域不再误触。
- **修复更多菜单恢复时机**：菜单打开期间保持卡片操作状态，实际关闭后再恢复图标与名称规则；支持取消、快速重按及重复关闭时的状态清理。

## 相对上次公开发布 260006 的累计更新

- 修复右侧可见任务卡片上滑时错误带动中间卡片的问题。
- 修复应用拖入小窗时实时画面变换被堆叠逻辑覆盖，以及取消小窗、手势条快速切换后的残留状态。
- 改善最近任务入场抖动、实时画面与截图交接、卡片大小回摆及动画连续性。
- 增加 **70%–120% 卡片缩放**，每档 1%，调整后保存；卡片大小与间距同比例变化。
- 改善堆叠图标的清晰、虚化、隐藏和恢复，修复图标被裁切；名称按实际可用空间显示，并保留拖动期间的遮挡规则。
- 保留横屏最近任务修复、卡片删除补位及原厂其他最近任务样式的处理。
