# 260017 · 横屏布局、侧边操作与动画连续性优化

- 内部版本：`260017`
- 显示版本：`26.9.260.908.2609081608`
- 包名：`com.zte.mifavor.launcher`

## 260017 最新修正

- **横屏入场交接**：修正前卡在入场末段偏上、切换为任务截图后再回位的问题；实时应用画面与截图按实际截图中心对齐，覆盖左右两种横屏方向及标题边距。
- **横屏尺寸与间距**：卡片宽、高调整为上一轮 77% 尺寸的 105%，即原始基准的 **80.85%**；堆叠中心间距收紧 **10%**，桌面首屏和历史页采用一致规则。
- **删除前卡后保持布局**：从应用进入最近任务后，删除右侧最新卡片时，保留其余历史卡片的位置、缩放与间距，避免删除收尾时再次左移或缩小。
- **保留缩放设置**：继续支持 70%–120% 自定义缩放，横屏调整基于保存值计算，返回竖屏恢复原有比例，不改写用户设置。

## 相对上次公开发布 260015 的累计更新

- **完整侧边操作**：长按卡片后，以弧形排列的白色圆形按钮展示原厂可用操作，包括信息、分屏、锁定/解锁、固定和小窗等；实际显示项目按原厂条件决定。已知操作采用统一线形图标，补齐原独立入口可用但菜单未列出的小窗操作。
- **自动选择展开侧别**：依据所选卡片完整截图在屏幕中线两侧的位置选择按钮方向，同一次展开、收回及中途重开保持方向一致；横屏同步调整按钮尺寸、图标方向、布局和触控位置。
- **长按展开与收回**：所选卡片为侧栏让出空间，其余卡片连续恢复完整截图后淡出；关闭时按原进度反向收回。点击外部、返回或选择操作后收起侧栏，所选原厂操作在收回结束后执行。侧栏移除关闭叉号，保留底部清理按钮。
- **入场、退出与打开应用的连续性**：应用手势入场接续实时画面的位置、尺寸与裁剪，已显示的截图不再重新归零透明度；退出最近任务时保留卡片当前布局，点击单任务时从当前截图位置接续应用打开动画。
- **长按和点击稳定性**：修正按住惯性滚动时长按偶发失效，以及普通短点击被长按状态清理干扰的问题；处理取消、多指、滑动、任务变化和重复触摸时的状态清理。
- **横屏与截图细节**：修正虚拟横屏的侧栏坐标和导航方向交接，缩小横屏操作按钮；删除收尾清除残留分页偏移；已有不透明截图时跳过多余浅色底层，减少截图边缘的亮边叠加。
