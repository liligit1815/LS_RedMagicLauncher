# 固定回归基线

`launcher-260005.apk` 是用户已验收的 260005 原始安装包副本，用于后续构建的签名证书、资源、原生库和资产回归检查。它是必须随 Git 克隆的固定构建输入，不是每次构建生成的新包；临时构建输出仍写入被忽略的 `out/`。

构建入口默认校验此文件的固定 SHA-256，并继续验证 APK 签名和构建载荷。文件缺失或哈希不符时停止构建，不会改用其他历史输出。详细版本、大小和校验值见 `manifest.json`。以后如需切换回归基线，应独立审查并同步更新文件、清单和构建入口中的固定校验值。

APK 中的签名和签名证书是公开校验数据，不含签名私钥。它们不能替代签名密钥。私钥和密码保存在被 Git 排除的 `.signing/`，换电脑时需另外安全备份、恢复；只运行 `--unsigned` 构建不需要读取私钥。

显式指定 `--previous <APK路径>` 可选择其他已审查的回归基线，仍必须通过预期证书和载荷检查。指定本目录的固定基线时，固定哈希校验始终生效。
